Find your cube's Bluetooth MAC address

Try Connect cube with the MAC field empty first. Enter an address only if Timer asks for it.

What address does Timer need?

The cube's Bluetooth MAC is six hexadecimal pairs, for example AA:BB:CC:DD:EE:FF. GAN protocols use it to derive encryption keys; automatic discovery is not always available in browsers. Other models may not require manual entry.

Use the cube's address, not your computer's Bluetooth adapter address, Wi-Fi MAC, device name, or serial number.

Windows: Microsoft Edge or Chrome

  1. Wake your cube using its manufacturer's instructions. If it is connected to another app, disconnect it there before scanning.
  2. Open a new browser tab. Paste the appropriate address into the address bar, then press Enter:
    Edge: edge://bluetooth-internals/#devices
    Chrome: chrome://bluetooth-internals/#devices
  3. On the Devices page, select Start Scan. Locate your cube by its advertised name; do not select the computer's adapter.
  4. Copy the cube's Address value, then stop the scan. Do not connect to the cube from the diagnostics page.
  5. Return to Timer. Paste the address into Bluetooth MAC (only if needed), then click Connect cube and select the same cube.

Internal browser pages must be opened from the address bar, not as ordinary website links. If this page or scanning is unavailable, use the Android method below.

Android: nRF Connect for Mobile

  1. Install nRF Connect for Mobile by Nordic Semiconductor. Enable Bluetooth and grant the scan permissions it requests.
  2. Wake the cube, start a BLE scan, and find it by name. Copy the Bluetooth address displayed with its scan result. You only need to scan, not connect.
  3. Stop scanning and return to Timer on your computer. Enter that address and connect.

iPhone, iPad, and macOS caveats

iOS does not expose the hardware MAC to normal Bluetooth scanner apps. An iOS device UUID is not the MAC Timer needs. Use Windows or Android to obtain it.

Do not use Chrome's Bluetooth-internals address on macOS for a GAN cube: the library author's FAQ warns that this value is not the real hardware MAC. See the FAQ below for macOS-specific alternatives.

Still not connecting?

  • If nothing appears, check Bluetooth is enabled, wake the cube again, bring it closer, and disconnect other apps using it.
  • Timer accepts uppercase or lowercase hexadecimal, with colons. Convert AABBCCDDEEFF or AA-BB-CC-DD-EE-FF to AA:BB:CC:DD:EE:FF before pasting.
  • A valid-looking but incorrect address can still produce an encryption/verification failure. Recheck the same cube's scan result rather than guessing.

Sources: GAN library author's MAC-address FAQ; Microsoft Edge internal pages; Nordic's scanner documentation; Nordic's iOS MAC-address explanation.
